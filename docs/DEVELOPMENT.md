# 正式版构建与验证

版本 1.0.2，versionCode 13，源码标识 `v1.0.2`。应用正式名称为「牛逼课表」。原生 Java，minSdk 26 / targetSdk 36 / compileSdk 37，无第三方运行时依赖。

## 离线构建

需要本机 JDK、Android SDK build-tools 36.0.0 和平台 android-37.0（或 android-37）。脚本不会下载 Gradle；Gradle 配置保留，本项目交付使用离线脚本。

```powershell
.\build-offline.ps1 -JdkPath '本机JDK路径' -SdkPath "$env:LOCALAPPDATA\Android\Sdk"
```

APK 输出到项目父目录。交付包沿用原签名以支持覆盖安装，签名证书摘要与构建结果记录在 [../verification.json](../verification.json)；私钥不入仓库。公开源码首次本地构建会生成自己的本地测试签名，它不能覆盖不同签名的安装包。请妥善离线保管自己的签名密钥。

## 当前验证

1.0.2 的验证仍在进行。当前已运行阶段、实际结果和未完成范围以 [../verification.json](../verification.json) 与对应测试结果文件为准；不要将旧版断言数、未重跑的协议/通知结论或基线证据写成本次通过结果。构建状态、签名和 APK 属性也只按当前验证记录陈述。截图应来自自有模拟器和合成数据，不包含真实学校账号或学生记录。

未验证项包括真实学校账号自动登录、原生 App 全量同步、全部 23 项教务业务流程、Xiaomi 15 Pro / Android 16（API 36）运行及真实设备重启。真实网络间歇失败的根因尚未定位；电脑上的一次访问结果不能外推到手机或其他时段。Android 后台调度可能受系统节电策略延迟。

## 维护规则

每个正式版一并更新 BuildInfo、Gradle 配置、离线构建脚本、使用声明、验证记录及本页和 README 的版本信息。未完成的测试不得写成 PASS，也不得复用上一版断言总数或未重新执行的协议、通知结论作为本版结果。功能说明、版本链接与 APK 大小须对应当前正式发布产物；README 下载按钮保持指向 `releases/latest`。

维护时先读 [../AGENTS.md](../AGENTS.md)、[FINAL_PROMPT.md](FINAL_PROMPT.md) 和 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。页面 ID 固定为课表 0、教务 1、设置 2，底栏位置从设置映射，不能拿按钮位置当页面身份。三份背景整体取色，前景缓存不依赖当前页。App 自有弹窗用 AppDialog；系统权限和文件选择器由 Android 显示。

课表校验并落盘后立即刷新课表并显示对号，其余模块继续更新；对号只表示课表成功，完整核心更新另行统计。失败模块保留各自有效缓存。课表、成绩、考试和其他模块按来源/模块覆盖快照；变更与通知去重上限为 100 条、90 天，并保留当前未读条目。普通官网断网、超时和访问拒绝应静默记录原因、保留缓存，不能据此宣称登录失效或官网崩溃。真实本地异常仍提供诊断。同步预算为整轮最多 120 秒、页面最多 35 秒。

凭据保存是可选功能，使用 Android Keystore + AES-GCM 保存应用私有密文，须由用户明确授权并可拒绝、修改或删除。App 需要联网，本机加密不能保证绝无泄露。只允许已核对的官方 HTTPS 表单在前台尝试一次；验证码和二次认证由用户处理，不绕过认证或 TLS。

切换学校账号前清除数据并退出，当前课表缓存没有完整账号隔离。自动采集仅限适配的只读查询；网站改版或无法识别时保留缓存并报告原因，不猜数据、不绕过认证或证书。详细限制见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。
