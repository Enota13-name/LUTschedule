# LUTschedule 正式版需求提示词

这是合并最终决定后的 1.0.0 基线。后续修改以本文件为准；被撤回或覆盖的要求不恢复。开发者署名固定为 Enota13，所有后续版本不可修改。

请维护轻量原生 Java Android App「课间 · LUT」，Android 8.0+，无第三方运行时、广告或分析服务，仅供个人非商业使用。仓库 https://github.com/Enota13-name/LUTschedule 。学校官网 https://jwxt.lut.edu.cn/ 。

1. 首次无有效数据时提供「登录 LUT 教务系统 / 导入课表文件」。不显示虚构课程，不保留演示模式。登录在官网全屏 WebView 由用户自己完成；确认登录后自动跳转个人课表并读取数据，不要求用户重复找页面。课表地址：https://jwxt.lut.edu.cn/jwapp/sys/wdkb/*default/index.do?EMAP_LANG=zh#/xskcb 。
2. 三页默认底栏「教务 — 课表 — 设置」，设置可选择全部六种排列并持久化；启动页始终是课表，排列不改变各页功能。页面切换有轻量动画，尊重系统关闭动画。
3. 原生重建整学期周课表：上方日期和周几，左侧按实际小节编号显示，支持官网周次、单双周、晚课和重叠课程。删除「课间 LUT」「这一周的课」标题，课表充分利用屏幕。无方格层、无跨日期整条底板，只有今天独立框及明显标记。课程名和楼宇在上，房间号单独固定在最底行。考试按已确认的真实日期、精确起止时间显示在课表对应日期，时间未定单列；不猜考试节次。
4. 周数切换、选周和本周集中在下角，左右位置可设置。首次有效课表时询问惯用手，决定默认位置。
5. 背景覆盖三页及按钮、底栏；选择图片后全屏按比例裁剪，双指缩放、单指拖动、预览、确认/取消，不留空边，取消不改旧图。可共用一张或将同一张图裁为连续三份；三份对应底栏从左到右，切换顺序后重新映射。根据三页背景整体占比最大色系选取同一黑/白字体；不逐按钮或逐页变色，课程底色保证文字对比。
6. 亮色、暗色、跟随系统；暗色通用界面用灰黑，课程保留多种暗色彩。课程可稳定随机多色或色盘选纯色，支持实时课程示例。背景参数称「透明度」，数值越高图片越清晰。界面以文本和简洁图标为主，减少圆角矩形；所有 App 自有弹窗采用统一简洁风格，网页和裁剪全屏。Android 权限、文件选择器和键盘遵循系统界面。
7. 教务按官网大类在左、小项在右显示文本目录；我的课表回原生主页，其余经已核对入口直接打开对应全屏官网服务，无须回门户多点一次。维护已核对的 4 类 23 项服务及同源只读采集。导入模式全部教务项目不可用，明确「这些选项仅为 LUT 学生提供」，且不得自动访问官网或混入官网成绩、考试缓存。
8. 官网模式每次打开/返回更新课表、成绩、考试及已适配的只读目录/查询内容。右上角同一状态按钮显示加载→完整更新成功对号→失败红叹号，可点击查看最近完整更新时间、尝试时间、各模块时间及刷新。单项失败保留有效缓存，区分离线、会话失效、官网异常和解析失败，不一律宣称官网崩溃。不绕过 TLS，不自动提交评教、选课、申请、收费或修改信息。
9. 新发布或更改成绩在顶部提示，并在允许通知时发送 Android 通知；首次建立基线不刷历史通知，保持未读与通知去重，锁屏隐藏明细。不发送评教提醒。考试安排同步更新课表。闲置 24 小时后第一个北京时间 08:00 仅后台检查一次，仅更新缓存，下次打开才提醒；新操作重新计时。用系统任务调度，不常驻、不承诺精确唤醒；导入模式无官网后台任务。
10. 设置按外观、课表与操作、同步与提醒、数据与隐私、关于与排查分组，错误报告在最底部。删除「背景布局」「官网小节」「演示模式」「官网连接详情」行及「权限与手机系统」分支；对应必要说明留在有关功能子页，保留裁剪布局选择、实际小节和诊断信息。
11. 本地有界、脱敏错误报告含版本、设备/Android/WebView、网络、来源状态、操作轨迹、错误阶段/原因链/堆栈、仓库和精确源码版本链接。普通错误弹窗指引到设置底部复制，致命异常下次启动恢复；不自动上传账号、会话、成绩、图片或报告。不承诺每个 AI 无需补充证据都能修复。
12. 开发者固定 Enota13，标注不可商用。署名单击无视觉/声音/振动反馈；连续五次点击复制 enota13official@gmail.com，弹出精确文本「你已经复制了开发者的邮箱，畅所欲言」。不发送邮件。
13. 课程来源分离存储，取消/失败不破坏缓存，导入后迟到的官网响应不得切回官网模式。清除数据并退出时清除会话与教务缓存；换账号前提示清除旧数据。仓库不包含密码、Cookie、真实学生记录、背景原图或签名私钥。

验收：核心规则、脱敏、原生导航/持久化/统一字体/真实双指裁剪/全屏网页/通知去重/一次性后台任务及生产冷启动按风险验证。使用通用合成数据，记录实际通过项；真实手机、真实账号、Android 后台限制等未验证项目明确列出。GitHub 首页、当前目录和下载区只呈现正式版，提供 APK、截图、需求、功能说明、复盘和验证记录。
