# 导入课表文件

使用 UTF-8 编码的 `.json` 文件，最大 1 MiB。导入文件只写入本机，不建立官网登录会话。选错文件、取消或校验失败不会替换已有课表。

```json
{
  "schemaVersion": 1,
  "semester": "2026 秋季",
  "firstMonday": "2026-08-31",
  "totalWeeks": 20,
  "periodCount": 10,
  "courses": [
    {
      "name": "课程名称",
      "teacher": "",
      "room": "教学楼 A201",
      "day": 1,
      "start": 1,
      "end": 2,
      "weeks": [1, 2, 3, 4]
    }
  ]
}
```

`firstMonday` 必须是第一教学周的周一；`day` 为 1–7（周一到周日）；`start/end` 是 1–24 的实际小节编号；`weeks` 明确列出上课周次。`periodCount` 包含空闲小节，应不小于最大课程结束节次，可省略并由课程推导。教师与地点可以留空。上面的内容只是字段写法说明，App 不会自动添加其中的课程。

导入后教务目录全部不可用，提示仅为 LUT 学生提供。若需要官网登录服务，在设置选择官网登录并完成身份确认；已导入文件与官网缓存分别保存，不会互相覆盖。当前不直接读取 PDF、照片、Excel 或 ICS。
