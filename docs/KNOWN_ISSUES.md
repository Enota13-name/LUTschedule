# 问题记录与修复范围

记录日期：2026-10-10。当前版本：1.0.2 / versionCode 13。旧版分析保留在 Git 历史及专项核对文档。本页不保存用户原始报告、设备标识、账号、课程或成绩。

## SYNC-001：返回应用时频繁弹出同步错误

1.0.1 会将普通超时送进待提示队列；前台停止时未取消采集，前后台还有争用风险。用户报告为非致命运行失败，没有本地崩溃堆栈。

1.0.2 将断网、超时、访问拒绝改为静默日志，保留缓存，状态详情显示原因。升级仅清除旧非致命 OperationalError 待提示标记，保留错误记录及真实异常。前台停止取消采集，旧票据失效；同进程统一会话所有权，前台优先。整轮最多 120 秒，页面单项最多 35 秒；明确连接失败时停止无效后续查询。真实本地异常仍提供诊断弹框，不能保证官网或手机网络永不超时。

## SYNC-002：课表已保存，主页仍等待其他查询

1.0.1 已先请求课表，但整轮结束才通知主页。注入延迟的合成测试中，课表第 1 秒保存、旧版主页第 18 秒才结束加载；这些数字不是官网速度。

1.0.2 在课表校验并落盘后立即刷新原生课表和对号。其他模块继续；考试保存后独立更新考试区，后续失败不撤回课表对号。采集忙碌独立于主页状态，避免重复启动。详情分开课表、完整核心更新和各模块时间。“完整更新”指课表、成绩、考试三个核心模块成功，不保证每个辅助页面均可识别。真实手机首屏秒数尚未测得，不承诺固定提速倍率。见 [原速度核对](SYNC_PERFORMANCE_2026-10-10.md) 与 [本版更新](UPDATE_1.0.2.md)。

单模块主文档 403/404/5xx 仅标记该模块失败，继续其余查询；401 认证失效、429 限流或明确连接/TLS 失败终止本轮，避免继续提交无效请求。

## NETWORK-001：官网间歇打不开尚未复现

状态：观察中，未定位根因。按用户授权沿用当前电脑代理，只读检查；未改代理、DNS、路由或 TLS，也未绕过代理直连。两批共六轮未认证 HTTP 请求成功，用户自行登录后能打开个人课表。这只证明该电脑和测试窗口可访问，不代表手机移动网络、WebView 或其他时刻正常。

HTTP 200 登录页不算课表获取成功。下一次失败需要同设备、同时间的文档/只读接口状态、登录状态与阶段耗时；证据不足时显示原因未确认，不能一律宣称官网崩溃。

## AUTH-001：访问拒绝曾被误认为登录失效

1.0.1 将 403 当作登录失效，fetch 未保留 401/403 状态码，jQuery 登录 HTML/parsererror 分类与 fetch 不一致。

1.0.2 保留状态码，401 与可识别登录页进入认证流程；403 表示访问拒绝，不凭一次 403/超时清 Cookie 或自动打开登录。未发现启动主动清 Cookie 的路径，登录和成功读取继续 flush。合成 Cookie 进程重建检查仅验证模拟器持久化，不代表学校服务器仍认可会话。

学校真实会话期限、并发规则和 Xiaomi 后台影响仍未确认。见 [会话核对](SESSION_AUDIT_2026-10-10.md)。可选本机凭据保存采用 Keystore + AES-GCM，首次/升级提示，可拒绝、更改、删除；仅授权后的前台官方表单尝试一次，验证码/二次认证交由用户。此功能不能延长学校会话期限；App 需要联网，本地加密不能保证绝无泄露。

未识别页面账号时，模块范围退回会话 Cookie 摘要；Cookie 也为空时无法可靠区分账号。课表缓存也没有完整账号隔离，换账号前仍需清除数据并退出。此限制未在本版解决，不把合成的已识别账号隔离断言扩展为所有真实会话保证。

## STORAGE-001：变更与通知去重原来没有总量上限

| 数据 | 当前策略 |
|---|---|
| 课表 | 按来源覆盖，官网/导入各一份；成功替换，失败保留 |
| 成绩、考试、辅助模块 | 按模块覆盖当前快照，不追加每次整份结果 |
| 变更收件箱 | 唯一 ID 去重，最多 100 条、90 天；读取也最多 100 条 |
| 通知去重 | 时间戳淘汰，最多 100 条、90 天；保护当前未读 ID，兼容旧布尔记录 |
| 错误、操作日志 | 最多 12 条错误与 24 条操作，不自动保存每次完整报告文件 |
| 自定义背景 | 原子替换当前图片，不保留上传历史 |
| 可选凭据 | 覆盖一份本机密文，可删除，不入日志或仓库 |

不会每次同步追加完整教务数据。本版限制原先无上限的变更/通知记录。WebView 网页存储由组件管理，没有承诺应用总磁盘容量上限；退出清除会话与网页存储。运行内存与磁盘不同，图片解码和 WebView 仍有独立内存开销。
