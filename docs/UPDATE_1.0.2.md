# 牛逼课表 1.0.2

本次更新修复返回应用后的同步体验、缓存增长和会话判断，保留已有排版、背景、导航顺序及固定署名。

## 优先展示课表

课表校验并保存后立即重绘、显示对号，不再等待其他查询。对号表示课表已更新；详情分开课表、完整核心更新及各模块时间。考试读取成功独立更新课表考试区，新成绩按既有规则提醒，后续查询失败不撤回对号。

前后台共享会话所有权，前台优先。离开应用取消前台采集，旧回调不得改动课表或弹登录。整轮预算 120 秒，页面单项最多 35 秒，确认连接失败后停止无效串行等待。

## 失败与缓存

普通官网断网、超时和访问拒绝保留缓存、静默记录，在状态详情说明；不再每次返回弹本地异常框。升级清除旧非致命 OperationalError 的待提示标记，错误记录仍可复制，真实本地异常继续提示。

课表、成绩、考试和辅助数据按来源/模块覆盖当前快照，不追加每次整份历史。本版给变更收件箱与通知去重增加 100 条、90 天上限。

## 可选保存登录信息

首次使用或首次升级提示一次，拒绝也能正常使用；保存需明确授权，设置可更改或删除。Android Keystore 密钥与 AES-GCM 加密，密文只放应用私有目录，不上传项目服务器、GitHub 或错误报告，应用禁止备份。退出关闭自动登录并尝试删除，删除失败如实提示。

自动填入仅允许核对过的官网 HTTPS 登录表单，前台只尝试一次，通过官网原按钮提交。验证码、二次认证、其他来源或用户已有手动输入时交由用户；不后台自动登录，不绕过认证/TLS。

App 必须联网，不能宣称没有联网功能或绝无泄露。本机加密降低保存风险，不能保证零风险，也不能延长学校会话期限。

## 仍需真实设备确认

修复了本地分类：保留 HTTP 码，401/登录页与 403 访问拒绝、超时、解析失败分别处理。没有证据表明学校会话频繁过期一定由官网或 WebView 单方造成。电脑代理保持原样，检查窗口内匿名请求成功，间歇失败未复现。

合成验证不能当作真实学校课表速度、会话期限或 Xiaomi 实机测量。实际构建、签名和测试结果见 [verification.json](../verification.json)、[运行结果](../tests/android/runtime-result.txt)；完整问题记录见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。
